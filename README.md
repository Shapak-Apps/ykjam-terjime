- Terjime konsoly — çeşme we niýetlenen dil: `TK` `RU` `EN` `ZH` `TR`

- Hytaý dili üçin transkripsiýa (pinyin)
- Gepleşik kitabynyň indeksi — 13 sahna, 295 sözlem
- Interfeýs üç dilde: türkmen, rus, iňlis
